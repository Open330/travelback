# Debugger — Travelback (2026-05-09, Cycle 10)

## Scope
Runtime bugs, race conditions, timing issues, and edge case failures.

## Findings

None. After reviewing all source files and test cases, no new runtime bugs were found.

## Analysis Details

### Race Conditions
- **useExportController.ts**: `exportAbortRef` guards against concurrent exports. `mountedRef` prevents state updates after unmount. Async operations (resize, waitForIdle) are awaited sequentially, not in parallel.
- **usePlaybackController.ts**: `awaitingFirstFrameRef` prevents duplicate play triggers. `mountedRef` guards cleanup.
- **ModalDialog.tsx**: Module-level `openModalStack` handles nested modal open/close sequences correctly.
- **TrackToolbar.tsx**: `closeMenu` uses `requestAnimationFrame` before restoring focus, ensuring DOM has updated.

### Timing Issues
- **renderFrameAndWait**: 5s timeout on `map.once('render')` + `requestAnimationFrame`. If MapLibre hangs, the timeout resolves gracefully.
- **waitForIdle**: 5s timeout on `idle` event. AbortSignal supported for cancellation.
- **TimelineSelector keyboard guard**: 3s window prevents leaked keys after keyboard interaction.
- **SceneEditor undo**: 5s auto-clear timer for deletion confirmation.
- **Export progress throttle**: ~100ms interval (~10 Hz) prevents excessive React re-renders.

### Memory Leaks
- **MapView cleanup**: Removes marker, layers, sources, and debug window properties on unmount.
- **useExportController**: `URL.revokeObjectURL` called on cleanup and reset. Module-level `prevFallbackAnchor` cleanup prevents DOM accumulation.
- **ModalDialog**: Restores previous `document.activeElement` on close.
- **ThemeToggle**: `matchMedia` listener removed on unmount. `requestAnimationFrame` cancelled.
- **TrackToolbar**: Event listeners (mousedown, touchstart, keydown) removed on menu close.

### Edge Cases
- **Zero-distance track**: `interpolateAlongTrack` returns first point, bearing 0.
- **Single-point track**: Returns the single point.
- **Empty track**: Returns origin `{lat:0, lng:0}`, bearing 0.
- **Antimeridian**: `wrapLngNear` and `shortestLngDelta` handle 179→-179 correctly.
- **NaN/Infinity coordinates**: Filtered by `parseOptionalNumber`.
- **Hidden tab**: Fallback `setTimeout(250)` maintains playback progress.
- **Blocked map style**: Error boundary shows recovery UI.
- **Export cancellation**: Abort signal propagates through `exportVideo` to frame loop.

### Worker Crashes
- **Worker RangeError**: `checkJsonDepth` preflight catches deep nesting before `JSON.parse`.
- **Worker message validation**: Validates `ext`, `buffer` type, and `byteLength` before processing.
- **Worker error handling**: Catches all errors and posts `{error, code}` message back to main thread.

## Verdict

No new runtime bugs, race conditions, or memory leaks found. Cleanup patterns are thorough and timeout guards are present on all long-running operations.
