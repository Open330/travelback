## Trace 4: Map style change during export — REAL BUG

**File**: `src/components/MapView.tsx:856-879` + `src/app/page.tsx`  
**Severity**: Medium  
**Confidence**: High  

If the user changes the map style during an active export, `map.setStyle()` removes all sources and layers mid-export. The frame loop then tries to read from sources/layers that no longer exist, producing blank video frames.

**Failure scenario**: User starts export → clicks a style toggle → map re-renders with new style → export continues with blank frames.

**Fix**: Disable map style controls during export. The `isExporting` prop is already available in `HomeInner`.
