## Scope

## Findings

### NEW-01: Mobile menu unit toggle buttons have incomplete accessibility labeling (Low)
**File:** `src/components/TrackToolbar.tsx`  
**Lines:** 232-249

The unit toggle buttons in the mobile menu (`TrackToolbar.tsx`) only render abbreviated visible text (`t('units.km')` / `t('units.mi')`) without `aria-label` or `title` attributes. Compare with `GlobalToolbar.tsx` (lines 28-49) where the same buttons include `aria-label={t('units.metric')}` / `aria-label={t('units.imperial')}`.

This creates an inconsistent accessibility data flow: screen reader users on desktop get "Metric units" / "Imperial units" context, while mobile users get only "km" / "mi".

**Suggested fix:** Add `aria-label` to mobile menu unit buttons:
```tsx
aria-label={units === 'metric' ? t('units.metric') : t('units.imperial')}
```

### State Flow: Export
1. `TrackToolbar` `onOpenExport` → `page.tsx` sets `exportPanelOpen`

3. `onExport` → `useExportController` `exportTrack`

5. `videoEncoder.ts` `exportVideo` → dynamic import mediabunny → encode frames
6. Progress throttled to ~10 Hz via `lastProgressUpdateTimeRef`
7. Blob + ObjectURL created → `showSaveFilePicker` or fallback anchor download
8. `URL.revokeObjectURL` on cleanup/reset

### Event Propagation

- `ExportPanel` also has `data-disable-playback-hotkeys="true"`.
- `ModalDialog` sets `inert` + `aria-hidden` on app root, trapping focus.
- Keyboard events in `TrackToolbar` mobile menu are captured at document level; `Escape` closes menu and restores focus.

### Lifecycle
- `MapView.tsx`: Cleanup effect removes marker, layers, sources, debug window props.
- `usePlaybackController`: `mountedRef` guard prevents state updates after unmount. Fallback timer cleaned up by `cancelAnimationFrame` / `clearTimeout`.
- `useExportController`: `exportAbortRef` for cancellation, `mountedRef` guard, `URL.revokeObjectURL` cleanup.
- `TrackToolbar`: `requestAnimationFrame` for focus restoration after menu close.
- `FileUpload`: Drag-end debounce timer cleaned up on unmount.
