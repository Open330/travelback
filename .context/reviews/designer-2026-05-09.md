# Designer — Travelback (2026-05-09, Cycle 10)

## Scope
UI/UX, visual design, responsive behavior, accessibility, and interaction patterns.

## Findings

### NEW-01: Mobile menu unit toggle buttons lack accessible labels (Low)
**File:** `src/components/TrackToolbar.tsx`  
**Lines:** 232-249

The unit toggle buttons in the mobile menu show abbreviated text "km" / "mi" without `aria-label` or `title`. The desktop `GlobalToolbar.tsx` provides full "Metric units" / "Imperial units" labels via `aria-label`. Screen reader users navigating the mobile menu receive less context than desktop users.

**Suggested fix:** Add `aria-label={units === 'metric' ? t('units.metric') : t('units.imperial')}` to mobile menu unit buttons.

## Analysis Details

### Visual Design
- **Vitro design system**: Liquid glass aesthetic with backdrop-filter, consistent across light/dark modes and map style variations.
- **Color system**: Teal/cyan accent (`--gl: 6, 182, 212`) with proper foreground color (`--gl-fg: #031015`).
- **Map style themes**: 5 bundled styles (Voyager, Positron, Dark, Liberty, Bright) each with custom `--gl` and background colors.
- **Mesh background**: Animated conic gradients with `prefers-reduced-motion` and export-pause support.

### Responsive Behavior
- **Mobile (<=390px)**: Type scale 0.89, touch scale 1.09.
- **Tablet (391-768px)**: Type scale 0.94, touch scale 1.05.
- **Desktop (>=1440px)**: Type scale 1.11.
- **Large (>=1920px)**: Type scale 1.20.
- **E2E tests verify**: Toolbar overlap prevention, control row separation, panel positioning, date label containment.

### Touch Targets
- All interactive elements use `min-h-11` (44px) minimum height.
- MapLibre control buttons enforced to `min-width: 44px; min-height: 44px` in CSS.
- Timeline drag handles are 44px touch targets.
- E2E bounding-box tests verify no overlaps.

### Focus Management
- **Global**: `focus-visible` with `outline: 2px solid rgb(var(--gl))` and `outline-offset: 2px`.
- **ModalDialog**: Focus trap with Tab wrapping, previous focus restoration.
- **TrackToolbar mobile menu**: Focus trap, first-button focus on open, trigger focus on close.
- **KeyboardHelp**: Modal with close button and title.
- **ExportPanel**: Modal with swipe-to-dismiss (vertical-dominant, >80px).

### Motion & Accessibility
- **prefers-reduced-motion**: 3 separate `@media` blocks covering marker-pulse, animate-spin, export-checkmark, vitro-btn-primary, and global catch-all.
- **prefers-contrast: more**: Touch scale increased to 1.1.
- **data-motion**: Supports `lite` and `off` modes in addition to system preference.

### Interaction Patterns
- **Timeline trimming**: Click-to-seek on selected region, drag handles with distance-based precision.
- **Scene editor**: Raw vs committed drag, undo with 5s auto-clear.
- **Journey creator**: Privacy-first search (opt-in), coordinate paste support, proximity threshold for waypoint clicks.
- **Export flow**: Resolution/codec selection, estimated time/size, progress bar with frame counter, share/download actions.

## Verdict

1 new finding (Low). One accessibility labeling gap in the mobile menu. Otherwise the UI is well-designed, responsive, accessible, and motion-aware.
