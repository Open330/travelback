## Discrepancies Found

### D1. Doc says "no runtime dependency on external tiles, glyphs, or sprites" — PARTIALLY VERIFIED
**Doc**: `.context/project/01-overview.md`
**Observation**: Map style JSON files are bundled locally. However, the style JSON files may reference external tile/glyph/sprite URLs internally. If they do, the browser would still make network requests for those resources.
**Recommendation**: Verify that bundled style JSONs use only local or data-URI references for all tiles, glyphs, and sprites.

### D2. Doc says "works offline after initial page load" — LIKELY VERIFIED
**Doc**: `.context/project/02-architecture.md`
**Observation**: All assets are bundled, and the app is a static export. However, if map styles reference external URLs (see D1), offline support would be broken for map rendering.
