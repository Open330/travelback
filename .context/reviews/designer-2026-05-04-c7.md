# Designer Review — Travelback (Cycle 7, 2026-05-04)

## Summary

The UI remains well-designed. One new finding regarding reduced motion preference.

## New Findings

### C7-DES1. prefers-reduced-motion not respected — LOW
**Files**: `src/app/globals.css`, various components
**Issue**: CSS animations (marker-pulse, landing-preview-image hover, transition-colors) have no `@media (prefers-reduced-motion: reduce)` overrides. Users who have enabled reduced motion in their OS settings would still see animations.
**Fix**: Add `@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; } }` to globals.css, or more targeted rules for specific animations.
