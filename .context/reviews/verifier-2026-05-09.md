# Verifier — Travelback (2026-05-09, Cycle 10)

## Scope
All claims made in source code comments, documentation, and test assertions.

## Findings

None. All verified claims hold true.

## Verified Claims

### Parser Security Claims
- Claim: "XML DOCTYPE/ENTITY declarations are rejected before DOMParser."  
  Verified: `parser.ts` strips `<!DOCTYPE` and `&` entities before DOMParser. E2E and unit tests confirm rejection.

- Claim: "JSON depth check prevents RangeError crashes in worker."  
  Verified: `checkJsonDepth` throws `ParseError('JSON_DEPTH_EXCEEDED')` before `JSON.parse`. Unit tests confirm.

- Claim: "File size limits: XML 4MB, JSON 100MB, general 200MB."  
  Verified: Constants match. E2E tests verify 4MB+ XML rejection and >1MB XML acceptance.

### Export Claims
- Claim: "Export video uses WebCodecs API via mediabunny."  
  Verified: `videoEncoder.ts` dynamically imports `mediabunny` and uses `VideoEncoder`.

- Claim: "Export test stub produces 26-byte files on localhost."  
  Verified: `test-stub.ts` checks `window.location.hostname === 'localhost'` and reads `localStorage` key.

- Claim: "Export progress is throttled to ~10 Hz."  
  Verified: `useExportController.ts` uses `lastProgressUpdateTimeRef` with 100ms threshold.

### Camera Claims
- Claim: "Scene transitions use smoothstep (3t^2 - 2t^3)."  
  Verified: `camera.ts` `lerpCamera` uses `t * t * (3 - 2 * t)`.

- Claim: "Overview camera uses WeakMap cache."  
  Verified: `camera.ts` declares `const overviewCameraCache = new WeakMap<readonly TrackPoint[], Camera>()`.

- Claim: "Antimeridian crossing is handled in lerpCamera."  
  Verified: `shortestLngDelta` used in `lerpCamera` for center interpolation.

### Playback Claims
- Claim: "Accumulator-based timing eliminates drift."  
  Verified: `usePlaybackController.ts` computes `nextProgress = startProgress + (elapsedSec * speed) / duration`.

- Claim: "Fallback timer runs when tab is hidden."  
  Verified: `if (document.visibilityState === 'hidden')` triggers `setTimeout(250)`.

### Accessibility Claims
- Claim: "ModalDialog implements focus trap."  
  Verified: `ModalDialog.tsx` finds first visible focusable, handles Tab/Shift+Tab wrapping, restores previous focus.

- Claim: "TimelineSelector has 44px touch targets."  
  Verified: E2E bounding box tests confirm handle geometry.

- Claim: "prefers-reduced-motion is respected."  
  Verified: `globals.css` has 3 `@media (prefers-reduced-motion: reduce)` blocks.

### Build Claims
- Claim: "CSP is hardened with SHA-256 hashes in static export."  
  Verified: `harden-static-export.mjs` computes hashes and replaces meta tag. `smoke-static.mjs` asserts hardened CSP.

- Claim: "Worker parser constants match main-thread constants."  
  Verified: `smoke-static.mjs` regex-matches `MAX_MESSAGE_SIZE`, `MAX_TRACK_POINTS`, and error codes between worker and parser.

## Verdict

All verified claims are accurate. No discrepancies found between code behavior and documented intent.
