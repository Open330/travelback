# Critic — Travelback (2026-05-09, Cycle 10)

## Scope
All TS/TSX source files, tests, and build scripts.

## Findings

None. After thorough review, no new issues of style, correctness, or design judgment were found.

## Analysis Details

### Code Style & Consistency
- **Conventional commit messages** with gitmoji are used consistently (verified in git log).
- **TypeScript**: Strict typing throughout. No `any` abuse. Proper use of `unknown` in parsers with narrowing.
- **Naming**: Clear and consistent. `camelCase` for functions/variables, `PascalCase` for components/types, `UPPER_SNAKE` for constants.
- **Comments**: JSDoc on shared utilities. Inline comments explain non-obvious decisions (e.g., antimeridian handling, CSP frame-ancestors omission).
- **File organization**: Components in `src/components/`, utilities in `src/lib/`, types in `src/types.ts`, styles in `src/styles/` and `src/app/globals.css`.

### Error Handling
- **ParseError** class with machine-readable `code` enables i18n error mapping.
- **ExportError** class with `code` for export-specific errors.
- **ErrorBoundary.tsx**: Recovery with `onReset`, localized messages, component stack in dev.
- All async operations have try/catch or error boundaries.

### Edge Cases
- **Empty tracks**: Handled in `interpolateAlongTrack` with origin fallback.
- **Single-point tracks**: Returns the single point.
- **Zero-distance tracks**: Returns first point, bearing 0.
- **NaN/Infinity coordinates**: Filtered by `parseOptionalNumber`.
- **Antimeridian**: Handled via `wrapLngNear` and `shortestLngDelta`.
- **Hidden tabs**: Fallback timer in playback controller.
- **Oversized files**: Rejected before parsing with user-friendly messages.

### Design Decisions
- Distance-based interpolation (haversine) instead of point-index-based is correct for uniform animation speed.
- Scene-based camera system with smoothstep transitions provides professional motion.
- Web Worker for JSON parsing keeps main thread free.
- Accumulator-based RAF eliminates timing drift.
- `preserveDrawingBuffer: true` on MapLibre canvas enables WebGL capture during export.

### Test Quality
- **219 tests** across 6 test files.
- Edge cases covered: NaN, Infinity, empty arrays, single elements, antimeridian, identical points, segment breaks.
- Unit tests for pure functions (interpolate, camera, parser, i18n, videoEncoder, env).
- E2E tests cover: file import, playback, scenes, export, theme switching, locale switching, mobile layout, keyboard navigation, error recovery.

## Verdict

No new findings. Code style, error handling, edge case coverage, and design judgment are all at a high standard.
